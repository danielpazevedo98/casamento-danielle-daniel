## 🚀 Como rodar localmente

1. Instale as dependências:
\`\`\`bash
npm install
\`\`\`

2. Copie as variáveis de ambiente:
\`\`\`bash
cp .env.example .env.local
\`\`\`

3. Rode o projeto:
\`\`\`bash
npm run dev
\`\`\`

4. Abra: http://localhost:3000

## 📤 Como fazer deploy na Vercel

Leia o arquivo **DEPLOY.md** — tem o passo a passo completo!

## 🎨 Estrutura

- \`/inicio\` — Página inicial
- \`/ceremonia\` — Informações da cerimônia
- \`/recepcao\` — Informações da recepção
- \`/presentes\` — Lista de presentes
- \`/confirmacao\` — Confirmação de presença
- \`/admin\` — Painel administrativo

## 🔑 Credenciais

Todas as credenciais já estão configuradas em \`.env.example\`.

Copie para \`.env.local\` e está pronto!
